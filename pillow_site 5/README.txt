PILLOW PARADISE WEBSITE

To preview: open index.html in a web browser.

Files:
- index.html: page structure and content
- style.css: colors, layout, and mobile styling
- script.js: product cards, add-to-cart, cart total, and demo forms
- assets/: pillowcase and bedroom images extracted from the supplied Photoshop design

This is a front-end school project. The cart is saved in the browser using localStorage. Checkout is a demonstration only; it does not take payments or place real orders. The contact form displays a demo confirmation and does not send email.
